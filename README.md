# منصة فريق إدارة الاتصال — هيئة تنظيم سوق العمل

منصة داخلية لفريق إدارة الاتصال، وفيها:

- **التقويم السنوي:** إجازات الفريق مع العطل الرسمية في مملكة البحرين.
- **المهام:** تصميم، وإنتاج فيديو، وتصوير، ورصد أخبار، وغيرها.
- **إحصائيات التصوير.**
- **الرصد الإعلامي ورصد السوشيال ميديا.**
- **التقرير اليومي:** بقالب الهيئة، ويتحمّل بصيغة PDF أو PowerPoint أو Word.

**رابط المنصة:** https://corpcom-team.vercel.app

المنصة ملفات ثابتة تنرفع على **Vercel**، وأي تعديل يترفع على فرع `main` ينشر تلقائياً. البيانات والدخول والصور كلها على **Supabase**.

---

## خطوات التشغيل (مرة واحدة)

### 1) إنشاء قاعدة البيانات على Supabase
1. ادخل [supabase.com](https://supabase.com) وأنشئ مشروع جديد. اختر منطقة قريبة، مثل **Middle East (Bahrain)** إذا كانت متاحة.
2. من **SQL Editor** افتح New query، والصق محتوى `supabase/schema.sql`، واضغط **Run**.
3. افتح query جديد، والصق محتوى `supabase/seed.sql`، واضغط **Run**. هذي الخطوة تنقل المهام والعطل الرسمية وأخبار الرصد وإعدادات الفريق.
4. أضف نفسك كمسؤول، وعدّل الإيميل بإيميلك:
   ```sql
   insert into public.team_access (contact, name, role)
   values ('your.email@example.com', 'معاذ محمد البرديني', 'admin');
   ```
   بعدها تقدر تضيف باقي الفريق من داخل المنصة عن طريق زر **«صلاحيات الدخول»**.

### 2) إعداد الدخول برمز الإيميل
1. **Authentication → Sign In / Providers → Email:** تأكد إن Email مفعّل.
2. **Authentication → Email Templates:** في قالبي **Magic Link** و**Confirm signup**، استبدل الرابط بالرمز:
   ```html
   <h2>رمز الدخول لمنصة فريق إدارة الاتصال</h2>
   <p style="font-size:28px;font-weight:bold;letter-spacing:6px">{{ .Token }}</p>
   <p>الرمز صالح لفترة قصيرة. إذا لم تطلب الدخول، تجاهل هذه الرسالة.</p>
   ```
3. **Authentication → URL Configuration:** حط رابط المنصة على Vercel في خانة **Site URL**.
4. ⚠️ خدمة الإيميل الافتراضية في Supabase ترسل عدد قليل جداً من الرسائل في الساعة. للاستخدام الفعلي، اربط خدمة إيميل من **Project Settings → Authentication → SMTP Settings**، مثل Resend أو Brevo أو بريد الهيئة.

### 3) (اختياري) الدخول برمز على الواتساب
1. تحتاج حساب **Twilio** فيه رقم واتساب معتمد (WhatsApp Sender).
2. **Authentication → Sign In / Providers → Phone:** فعّل Phone، واختر Twilio، وأدخل بيانات الحساب.
3. في ملف `config.js` غيّر `whatsapp: false` إلى `whatsapp: true`.
4. أرقام الفريق تنضاف في «صلاحيات الدخول» مع مفتاح الدولة، مثال: `97333123456`.

### 4) ربط المنصة بقاعدة البيانات
عدّل `config.js` بالقيمتين اللي تحصلهم في **Project Settings → API**:
```js
supabaseUrl: "https://xxxx.supabase.co",
supabaseAnonKey: "eyJ..."   // anon public key
```
> مفتاح `anon` مصمم إنه يكون علني. الحماية تجي من صلاحيات قاعدة البيانات (RLS): ما يقدر أحد يقرأ أو يعدّل إلا الأشخاص المضافين في `team_access`.

### 5) النشر على Vercel
1. في [vercel.com](https://vercel.com) اضغط **Add New → Project**، واختر المستودع `corpcom-team`.
2. Framework Preset: **Other**. لا تغيّر أي إعداد ثاني، ما يحتاج Build.
3. اضغط **Deploy**. أي تعديل ترفعه على GitHub بعدها ينعكس على المنصة تلقائياً.

## الدخول
- جميع أعضاء الفريق (بمن فيهم المسؤولون) يدخلون بكتابة الإيميل المسجّل فقط (دالة `supabase/functions/quick-login`).

## الصلاحيات
| الصلاحية | يقدر |
|---|---|
| **مسؤول (admin)** | كل شي، ومعها إدارة قائمة الدخول |
| **عضو (member)** | يضيف ويعدّل الإجازات والمهام والرصد |
| **مشاهد (viewer)** | يشوف بس |

## الملفات
- `index.html`: المنصة نفسها.
- `js/backend.js`: ربط المنصة مع Supabase، وفيه شاشة الدخول وإدارة الصلاحيات.
- `config.js`: إعدادات الربط.
- `lib/`: مكتبات التصدير (PDF وPowerPoint وWord) ومكتبة Supabase.
- `rpt/`: عناصر قالب التقرير اليومي.
- `supabase/schema.sql`: هيكل قاعدة البيانات والصلاحيات.
- `supabase/seed.sql`: البيانات المنقولة.

## ملاحظات
- صورتين من صور أخبار الرصد كانت مرفوعة على النسخة القديمة وما انتقلت. ترجع ترفعهم من «تعديل» في الخبر.
- زر «صياغة الملخص بـ Claude» غير مفعّل في هذي النسخة، والملخص يُكتب يدوياً.
